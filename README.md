## Workflow

```txt
diagnose -> design smallest maintainable fix -> test each layer
deploy with rollback -> verify original issue -> measure in production
```

| Layer | What I check |
| --- | --- |
| Application | UI behavior, validation, console errors, responsive layout, RTL edge cases |
| Server | Apache, PHP-FPM, OPcache, compression, cache headers, SSL, redirects |
| CDN | Cloudflare DNS, cache rules, bypass behavior, origin-vs-CDN differences |
| Tracking | GTM, GA4, Google Ads, Meta Pixel, form success, CTA, chat, UTM, GCLID |
| Release | Backups, minimal edit scope, linting, smoke tests, cache clear, monitoring |
