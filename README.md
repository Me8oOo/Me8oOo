## Engineering method

1. Diagnose the user-visible failure, not only the code symptom.
2. Design the smallest maintainable change that fixes the real problem.
3. Test each layer: application, server, CDN, tracking, and browser behavior.
4. Deploy with rollback, backups, and targeted verification.
5. Confirm the original issue is gone.
6. Measure the result and keep watching production.
