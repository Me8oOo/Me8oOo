🚀 Featured Projects

Healthcare Website Infrastructure Rebuild

Led the migration of a live Joomla/Gridbox production website into a WHM/cPanel environment.

The project covered DNS, SSL, databases, backups, permissions, Apache, PHP-FPM, OPcache, Cloudflare, security hardening and final production validation.

Result: Mobile PageSpeed improved from approximately 18 to 85–90+.

WHM/cPanel Cloudflare Apache PHP-FPM Joomla Core Web Vitals

PageSpeed Insights Dashboard

Built a custom PHP and JavaScript dashboard for large-scale website performance monitoring.

The system includes queued tests, six parallel workers, automatic retries, URL retesting, historical JSON storage, CSV exports and Lighthouse-style reports.

PHP JavaScript PageSpeed API JSON CSV

Conversion Tracking Infrastructure

Rebuilt the full conversion architecture across Google Tag Manager, Google Analytics 4, Google Ads, Meta Pixel, appointment forms, CTA clicks, chat events, UTM parameters and GCLID attribution.

The result was a cleaner event map, fewer duplicate signals and more reliable campaign data.

GTM GA4 Google Ads Meta Pixel Attribution

Bilingual Appointment and CRM System

Developed an Arabic and English appointment workflow with RTL support, UAE mobile validation, timezone-aware date logic, spam protection, cross-origin attribution, CRM integration and conversion event sequencing.

Arabic / English RTL Forms CRM Analytics

Bilingual CRM Chatbot

JavaScript Zoho SalesIQ CRM Arabic / English
